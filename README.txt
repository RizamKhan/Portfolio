CSC 337 — Assignment 1 Portfolio Website
==========================================

Project files
-------------
index.html       Home page
hobbies.html     Hobbies, lists and two tables
media.html       Social media-style content, local/online images and 5 YouTube embeds
contact.html     Contact details, friends table, contact form and Google Map
css/style.css    One external stylesheet linked from all four pages
assets/          Local SVG illustration and favicon

How to view
-----------
1. Extract the ZIP file.
2. Open index.html in a web browser.
3. Use the navigation menu to visit all four pages.

Before submitting — PERSONALISE THESE DETAILS
----------------------------------------------
- Add your roll number if required.
- Replace the sample email and phone number on contact.html.
- Replace the sample friend names and student IDs on contact.html.
- Replace the sample friend/game ID on hobbies.html.
- Check that the YouTube embeds and online Unsplash images load on your network.
- The contact form uses a mailto action; update its email address.
- Add your own GitHub repository and live GitHub Pages link to your report.

Publishing on GitHub Pages
--------------------------
Upload the contents of this folder to a public GitHub repository. Keep index.html
in the repository root. In Settings > Pages, select branch main and folder /(root).

Notes
-----
- The project uses HTML5 and CSS3 only; no JavaScript is included.
- Online images, Google Maps and YouTube embeds need an internet connection.
- The assignment asks for validator screenshots, responsive screenshots and
  at least 10 meaningful Git commits. These must be completed by the student.
